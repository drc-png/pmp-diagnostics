Before You Begin

Response types: Single response, select-two, matching, artifact practicum, and dashboard hotspots. Each item is worth one point. Multiple-response and multi-part items require the complete correct response; no partial credit is awarded.

This is not a memorization quiz. Every item tests project-management judgment through close, defensible-looking responses. Expect executive judgment, AI governance, sustainability, stakeholder politics, value delivery, risk, compliance, and integrated delivery tradeoffs. Read what the scenario tells you has already been done — it usually determines the correct next action.

Academy practice GO/NO-GO rule (not a PMI passing score): A GO requires at least 85% overall, at least 78% in each domain, at least 75% on Hard items, and a response to all 180 scored items within the allotted time. Missing any gate produces a NO-GO recommendation with the specific repair priorities shown in the report.

Interface practice: After you select Begin Diagnostic, you will first see three unscored practice items in the same exam interface. Practice responses are not saved, scored, submitted, or included in your report. The 240-minute timer begins only after practice is complete and you select Begin Scored Diagnostic.

Flagged-question review: Use Flag for Review on any question you want to revisit. During the exam, the Section Flags button jumps to flagged questions in the current unlocked section; after that jump, use Return to Current Question to go back to where you were. At a section break, use Review Flagged or Review Unanswered before starting the break. Once you select Finish Section and Begin Break, that section is locked.
